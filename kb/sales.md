## kb:products
제목: 상품 구성
출처: 영업팀 상품 안내
검토일: 2026-10-01
validUntil: 2027-06-30

상품은 기본형과 맞춤형 두 가지입니다. 기본형은 정해진 기능 구성과 좌석 단위로 바로 시작할 수 있어 팀 규모와 필요한 기능이 정해져 있을 때 맞고, 맞춤형은 조직 구조와 연동 요구를 먼저 확인한 뒤 구성을 정하는 방식이라 연동이나 보안 요건이 많을 때 맞습니다.

## kb:process
제목: 진행 순서
출처: 영업팀 상품 안내
검토일: 2026-10-01
validUntil: 2027-06-30

진행 순서는 [문의 → 요구사항 확인 → 상품 제안 → 비용 확정 → 계약 → 초기 설정 → 사용 시작]입니다. 요구사항 확인 단계에서 담당자가 팀 상황을 듣고 맞는 상품을 제안드립니다.

비용은 기본형의 경우 좌석 수와 기능 구성에 따라 정해지고, 맞춤형은 요구사항을 확인한 뒤 구성에 맞춰 산정합니다. 정확한 금액은 요구사항 확인 뒤 담당자가 견적으로 안내드립니다.
